## Cybersecurity awareness notes

## Introduction
It is a project that provides cybersecurity awareness information for university students. It focuses on common cyber threats and ways students can protect their information.

## Project Objectives
- Identify common cybersecurity threats.
- Recognise suspicious emails and links.
- Learn how to protect passwords and online accounts. 
- To understand how to report cybersecurity incidents.
